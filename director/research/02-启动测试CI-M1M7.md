## A. M1 启动手册

**脚本链**:postinstall=electron/scripts/rebuild-native.mjs(better-sqlite3 ABI 重建)→ `./start.sh`(node22 门禁,自动 nvm use/install;.env 自动生成含 SECRETS_MASTER_KEY;首装设 ELECTRON_SKIP_BINARY_DOWNLOAD=1)→ build:packages(turbo,装饰器包走 dist)→ dev。

**两种 canvas 形态**:
- 开发态:`npm run dev` = API:7777 + Vite:3000(canvas 在 **localhost:3000**,proxy /api /ws → 7777)。
- 单端口态:`STATIC_FOLDER=web/dist npm run dev:server` → canvas 直接在 7777(Docker/生产布局)。

**命令序列(冷启动)**:
```bash
node -v                          # 必须 v22.x(start.sh:38-47 硬门禁)
./start.sh doctor                # 环境自检(只读报告)
./start.sh                       # install+rebuild+build:packages+dev:server
# 手动等价:ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm install && npm run build:packages && npm run dev:server
```
- 成功信号:`Server listening on http://...:7777`;/ready(轻活探针,scripts/wait-for-api.mjs:9-14);/health(带 DB ping)。
- ⚠️ 端口被占时 dev-server **exit 0** 并打印提示——勿误读为成功(dev-server.mjs:71-88)。
- SQLite/Drizzle 自动建库迁移;本地模式免登录(loopback 信任,.env.example:19-25);SECRETS_MASTER_KEY 自动生成。

**常见故障表**:代理下安装回滚→`ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm install --no-audit --fund=false`(纯 JS 工作 `--ignore-scripts`);ABI 不匹配→`npm run rebuild:native`;改装饰器包后缺类型→先 `build:packages`;WebGPU 报错 macOS 不预期(Metal 走 Dawn)。
