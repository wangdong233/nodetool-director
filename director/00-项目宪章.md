## 1. 定位

NodeTool 私有 fork 二开 = **AIGC 导演台**。本机(macOS)开发+指挥,Windows 机器跑全流程(GPU 合成)。media-gen-mcp 保持独立 MIT 项目,**本仓只消费/转写其契约,不改其归属**。

```
Windows 主机(全流程) ←私有仓 clone─ Mac(开发机,CC 会话,可远程访问 Windows:7777)
  nodetool-director
    ├─ packages/mediagen-nodes   ← 自建 node pack(核心工作量)
    ├─ custom provider(智谱 OpenAI 兼容端点,零代码)
    ├─ credit 预算闸(job/Runner 调度处)
    └─ director/                 ← 本项目全部自有文档/飞轮记录(收敛改动面)
```

## 2. 三条铁律(继承实施方案,不可违背)

1. **media-gen-mcp 不改归属**:fork 只以 MCP 挂入(chat 层)或 node pack manifest 转写其 wire 契约;MIT 代码可单向流入,不回流义务。
2. **AGPL 边界**:私有自用合法;不对外分发闭源二进制;渠道层独立在 media-gen-mcp,迁移门常开。
3. **上游同步收敛**:我们的改动集中在 `packages/mediagen-nodes/` + `director/` + 少量已登记 hook 点(02-基线.md 的 hook 清单);上游极活跃,同步以月为周期、以演习为验证。

## 4. 磁盘写纪律(本机硬件约束)

- 开发机 SSD(Kingston A2000)有写入敏感史;**一切大写入操作必须计量**。
- 协议:阶段边界 `diskutil activity` 快照差分(累计 Reads/Writes 计数),记录到 `director/logs/disk-*.md`;iostat 采样日志常驻(`项目/aigc-nodetool-diskmon.log`,仓外)。
- 预算:初始化 ~10GB 已批;此后每迭代目标 ≤5GB;单命令预计 >2GB 写入(如全量重装 node_modules)须先在迭代报告登记再执行。
- 减写手段优先:本地 bare 硬链克隆、node_modules 复用不重装、turbo 缓存保留、避免重复 clone。
