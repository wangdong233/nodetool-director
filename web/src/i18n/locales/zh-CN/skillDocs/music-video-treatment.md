# 音乐视频创意方案 → 分镜 Agent

产出一份完整、可拍摄的音乐视频创意方案,并落成 NodeTool 分镜。直接通过分镜与实体两组能力工具完成。不要搭工作流或管线。除非被要求,不要渲染或装配时间线。

## 简报与真实性

要求以下信息:艺人与人设、曲名、流派、BPM、拍号、曲长、带时码的段落表、演出与叙事的配比、投放平台、基调,以及任何必须包含或禁止出现的内容。BPM 与段落表是硬性输入。既没有段落表也没有音频时,先问,不要凭空编小节数。未知的艺人、厂牌、发行、歌词或制作信息,标为 `[ARTIST INPUT NEEDED]`。

## 实体名单

起草段落之前先敲定名单:优先用用户给的参考图,其次 `list_entities`,只为缺失的参考生成。艺人永远是角色实体,用户给的宣传照绝不重新生成。先敲定风格实体;把它应用到生成的艺人、场地与道具上。常规名单保持在 4–7 个实体:风格、艺人、1–2 个场地、0–2 个标志道具。创意方案起草前把名单展示出来,并标注生成的艺人是替身。

## 音乐网格与创意方案

按 `(60 / BPM) × beats per bar`(60 除以 BPM,再乘每小节拍数)算出每小节
的秒数,把每个段落换算成小节与时码,并让每个转场落在小节、拍点或歌词上。构建三个彼此不同的方向,各带演出/叙事配比、可复用的副歌钩子镜头、drop 事件、风险与实体名单。用不超过两句话推荐其中一个。

每个段落给出时码与小节区间、音乐与画面各自的职能、构图、焦段/角度、运镜、画面/动作、卡点、实体、演出内容、适用时的歌词文本、布光、调色/效果、转场,以及它为什么能剪在一起。演出与叙事穿插推进。最大事件落在 drop 或第一段副歌的强拍上;每段副歌重复钩子镜头;最后一段副歌前安排一次刻意的节奏休止;尾奏呼应前奏。

## 落盘分镜板

用 `create_storyboard({ name, brief, style, aspect_ratio })` 建板,取结果里的 `storyboard_id`,绝不用 `.id`。把完整简报、歌词、段落表、小节网格与实体名单都写进 `brief`。这次调用所牵涉的、所有分镜类技能共用的契约——实体 id 等于你传入的素材 id、五类 `edit_storyboard` 操作、`set_board` 接受什么、生成器实际读哪些文本——都在 `commercial-beat-sheet` 的 § Tool contract 一节。

用 `edit_storyboard({ storyboard_id, ops: [{ op: "set_board", entity_ids, image_model, video_model }] })` 挂上实体 id(`set_entities` 只是别名)。两个模型各来自一次 `find_model` 调用的 `.ref`,分别对应 `text_to_image` 与 `image_to_video`;写镜头文本前先加载各自指定的 `prompting_skill`,因为 `motion` 加 `action` 就是剪辑提示词的逐字原文,而演出段落在 Kling 的分镜表、Hailuo 的有序节拍或 Seedance 的声音简报里措辞各不相同。

每个段落加一条 `add_shot` 操作。每条 action 文本在方括号里点名可见实体,写明卡点,时长用该段落时长取整到 0.5 秒。渲染时只有当艺人或道具的名字出现在某镜头的文本里才把它挂到该镜头上(风格与场地总是生效),所以艺人的名字要写进每个演出镜头,或落在那个镜头自己的 `entity_ids` 上。屏幕上的歌词文本是给剪辑看的备注,装配后作为文字片段加上(`caption-titles`),不进渲染提示词。

到规划好的板为止,除非被要求渲染。汇报各方向、选定的创意方案与实体名单。

## 渲染(仅按需)

先用 `render_storyboard_stills` 出静图;用 `view_image` 逐张看、问哪里不对;艺人形象漂移在实体上修,绝不在单个镜头的提示词里修。再用 `render_storyboard_clips` 出剪辑;时长要得比段落需要的更长(用 `update_shot` 调大 `duration_seconds`,事后再改回),让剪辑在拍点上有帧可选。静图对、剪辑错的片段,用一次 `revise_storyboard_clip` 修。然后 `assemble_storyboard_timeline`。

## 当创意方案变成成片

上面算出的小节网格只是计划;`beat-sync-editing` 用 `detect_audio_events` 从曲目推导真实网格,并把剪切吸附上去,所以两套网格必须先对齐才能修剪任何东西。这里曲目就是连贯性的载体,所以各段落剪辑分开渲染并静音各自的音频——某段素材没有自己的音轨时的处理见 `video-audio-continuity`。`motion-graphics` 承载时间线操作契约,`color-motion` 承载分段调色与 drop 上任何随节拍变动的色彩,`frame-composition` 承载副歌间反复出现的钩子构图,`caption-titles` 承载屏幕上的歌词卡与艺人卡。
